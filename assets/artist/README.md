# Artist references

Add your partner's approved PNG, JPEG, or WebP reference drawings here, then list the filenames in `art-direction.json` under `references`. Up to four references, at most 12 MB each. Update the label, description, rules, and version to match the intended style.

The server hashes the rules and image bytes at startup. Each new invitation binds that hash into both holders' signed permission. Changing any of these files requires new invitations and approvals; old signatures cannot authorize a new style.

These references are sent with the two parent images to the configured image provider when generation starts. Add only artwork your collaborator has agreed to use for this purpose.

`comic-fusion-reference-v1.jpg` is the finished fusion drawing supplied by [@theejhay01](https://x.com/theejhay01), the project's collaborating comic artist. It guides outlines, color, texture, and shading; the two selected NFTs provide each new character's features. It is an artist reference, not an AI-generated gallery record. The supplied file is preserved without editing; its extension matches its actual JPEG encoding.
